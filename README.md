## SQLite, Cache, dan Mode Offline

**Cache-segar** adalah data yang tersimpan kurang dari 30 menit sehingga dapat langsung ditampilkan tanpa mengambil data dari internet.

**Cache-basi** adalah data yang sudah melewati batas waktu 30 menit. Jika internet tidak tersedia, aplikasi tetap menampilkan data tersimpan dan memberi tahu pengguna bahwa data mungkin sudah usang.

**First-run offline** adalah kondisi ketika pengguna membuka kota yang belum memiliki data tersimpan saat tidak ada koneksi internet. Aplikasi menampilkan pesan bahwa data belum tersedia.

Fitur offline penting agar pengguna tetap dapat melihat data cuaca yang pernah disimpan meskipun koneksi internet sedang tidak tersedia.
